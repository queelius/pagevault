# pagevault v0.4.0 Architecture Overhaul Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform pagevault from a codebase with drifting duplicated JS runtimes into one with a first-class runtime module, a single unified envelope format, and a split CLI.

**Architecture:** Extract all browser-side JavaScript from Python f-strings into real `.js` files under `src/pagevault/runtime/`, loaded via `importlib.resources` and composed at import time with a single `CONFIG` prelude. Replace v2 (attribute-embedded) envelope with a unified v4 format that uses chunked script-tag envelopes everywhere (regions, files, sites) with a `meta.kind` discriminator. Split the 2155-line `cli.py` into per-command modules. Add Node-based JS unit tests.

**Tech Stack:** Python 3.10+, hatchling build, Click CLI, `importlib.resources`, hypothesis, Node.js 20+ (`node:test` + `node:vm`, no npm deps).

**Constraints:**
- **NO backwards compatibility.** v0.3.x encrypted files do NOT need to decrypt in v0.4.0.
- Tests must pass at each chunk boundary.
- Commits are per-task, not per-chunk.

---

## Execution Guidance For The Implementer

This plan instructs you to EXTRACT JavaScript from existing Python source files into standalone `.js` files. For each extraction task:

1. **Read the current source** at the path/line range given.
2. **Copy the JS verbatim** to the target `.js` file.
3. **Collapse f-string escapes:** `{{` → `{` and `}}` → `}` (Python f-string literals of braces).
4. **Remove f-string interpolations:** `{template.color_primary}`, `{_js_string(...)}`, etc. Replace with `CONFIG.foo` references that will be populated by the config prelude.
5. **Verify:** the `.js` file must be pure JavaScript with no Python-specific syntax.

Do NOT try to transcribe JS snippets from this plan; they are illustrative summaries. Always extract from the current source.
